# МПСУиД 2ЭС6 — нормативная карта экранов

Дата: 2026-10-11. Область: первичное описание мониторов **2ЭС6.00.000.000 РЭ2, §1.7**. Это нормативная часть аудита, а не заключение о прохождении всех экранов тренажером. Исполнитель не запускал Native Test/Run и не менял production. Указанные ниже листы — **печатные листы РЭ2**, не номера страниц локального PDF электрических схем.

## Источники и доступность

- **R21** — [РЭ2, §1.7.1–1.7.5, листы 47–60](https://zinref.ru/000_uchebniki/04600_raznie_6/358_Elektrovoz_2ES6_rukovodstvo/021.htm). Зеркало первичного РЭ; текст прочитан через поисковый кэш, в том числе целевые запросы по §/рисункам/условиям сигнализации.
- **R22** — [РЭ2, продолжение §1.7.5–1.7.16, листы 61–76](https://zinref.ru/000_uchebniki/04600_raznie_6/358_Elektrovoz_2ES6_rukovodstvo/022.htm). Аналогичный доступ к тексту.
- **R23** — [РЭ2, §1.7.16–1.7.17, листы 77–79](https://zinref.ru/000_uchebniki/04600_raznie_6/358_Elektrovoz_2ES6_rukovodstvo/023.htm). Текст включает числовые коды БУК и назначение настройки времени.
- **RB** — [титул/оглавление РЭ2 на RCIT](https://rcit.su/techinfoU7.html): часть 3, изготовитель ОАО «УЗЖМ», утверждение 29.04.2008. **Оглавление само по себе не подтверждает алгоритмы или поля экранов.**

Графические оригиналы рисунков 1.18–1.39 не были получены: поисковый кэш показывает подписи рисунков и окружающий текст, но не разрешает прочитать все надписи внутри картинки. Полный файл части 3 `3chast-.pdf` из [публичного архива](https://yadi.sk/d/BgsyV7dp3KwbS4) не скачан. У архива проверен центральный каталог: ZIP entry offset 230611830, compressed size 38952066, uncompressed size 43029491, начало данных 230611871. Эти числа являются координатами загрузки, а не доказательством содержания PDF.

Попытки получения источника зафиксированы в `work/mpsud_screen_sources/source_availability.json`. API Яндекс.Диска вернул метаданные HTTP 200, но чтение ZIP по HTTPS завершилось тайм-аутом. Новый ограниченный запрос PowerShell также не получил 64 КБ за 15 с. Ссылка `https://scbist.com/scb/uploaded/2es6_re3.pdf` вернула HTTP 404. Локальный `work/public_2es6_part1.pdf` описывает электрические цепи и не подменяет РЭ2 с рисунками монитора. Современные руководства МПСУ-БД для 2ЭС6 из каталога НПО САУТ также не подменяют МПСУиД/МСУЛ-А этой редакции.

## Подтвержденные нормативные условия

**R21, §1.7.1–1.7.4.1, листы 47–57:** два монитора/две независимые клавиатуры; автопитание ИП-ЛЭ. Главные режимы: 2/3/4/5; возврат 1. Uкс голубой; Ia тяга зеленый, рекуперация сине-фиолетовый; Iv темно-голубой. Ведущая секция: токи групп; ведомые: максимумы. Потеря аналоговых данных: желтые нули. По секциям: БВ/ПСН/МВ/МК/ДР/БК/ТМ/ВВК/ТЦ. Нет связи: белый текст/черный фон; связь: зеленый/черный; включено: черный/зеленый; отказ: черный/красный. Задержки БВ/ПСН/МВ/МК: 3/8/5/5 с при требуемой команде и отсутствии/потере подтверждения. ДР: возврат 2 с. ВВК: заблокирована — черный фон, разблокирована — красный. ТЦ: есть сигнал давления — зеленый, нет — черный. Краткий красный ТМ при торможении — контроль исправности. Дискреты: 3×2; аварийный кворум — два элемента разных столбцов. Аналоги: 2/3 поля. АВП: ф/р, позиция, сила, МВ, ось/секция скольжения. Позиции С/СП/П:1–23/24–44/45–65; рекуперация:0–1; реостат:1…xx. Сила:1…120/−1…−100%; последовательное возбуждение — без силы.

**R22, §1.7.5–1.7.15, листы 61–76:** SR08 — команды/обратные связи схемы; SR09 — БСП/БУК/БВС-БЗС; SR10 — уставки МВ двух групп, позиция, Iv, контакторы/жалюзи. SR11 — БС-СИ/БЗС/энергия по каналам/линиям; мегомметры; ошибки связи 1–2 межблочные, 3–4 межкузовные; индекс/число секций. SR12 — C1…C4. SR13 — БС-ПС/БС-УВ/РН3000. SR14 — регуляторы №1/№2. SR15 — команды БЦВ, измеренные Ia/Iv, статусы СТПР. SR16 — частотные преобразователи. SR17 — два калорифера, температуры кабины/воздуховода. SR18 — ПУ/СВЧ, неисправности микроклимата, заданные/фактические температуры. Контактные варианты показывают привязку блока/входа. Переходы 3–9 внутри состояния; выход 1; подменю ПСН 3–7.

**R23, §1.7.16–1.7.17, листы 77–79:** диагностика раздельна по каналам/линиям; неисправный БУК красный. Коды выходов: **0** исправно; **1** обрыв нагрузки; **2** перегрузка; **3** обрыв ключа; **4** КЗ нагрузки; **5** КЗ ключа/диода. Настройка меняет дату/время заставки; выход 1.

## Что еще нельзя считать нормативно проверенным

**SOURCE_GAP, не подтвержденный дефект тренажера:** полный перечень строк/единиц/диапазонов на каждом из рисунков, подписи функциональных клавиш внутри рисунков, числовые значения на примерных экранах, точная компоновка, размеры шрифтов и RGB, поля ввода АВП и временных ограничений, полный каталог сообщений, графические состояния отдельных неисправностей. Они требуют читаемого оригинала рисунков. Типовой пример показаний на рисунке также нельзя автоматически считать обязательной уставкой.

**REVISION_DEPENDENT:** старый HTML РЭ2 описывает регулирование МВ по току; локальные замененные листы электрических цепей §3.10.3 (лист 90/PDF95, поправка 6/226.020-12) задают сезонный алгоритм. Перед классификацией расхождения индикатора МВ необходимо установить применимую ревизию/комплектацию. Доказательства и SHA локального скана приведены в `MPSUD_CONTROL.md`.

**NOT_EXECUTED:** матрица текстовых требований не доказывает рендеринг MSUL.dll. Нужны свежие снимки каждого штатного окна и переключения обеих клавиатур в том же загруженном runtime, проверка изменяющихся входов, исчезновения данных и неисправностей. Статический поиск имени формы/поля, цвета в ресурсах или вызова метода не заменяет этого.

Для дальнейшей приемки предлагается сохранять на каждое SRxx: путь PNG, фактическое имя/индекс native окна, исходное/целевое состояние клавиатуры, входные значения с единицами/секцией, ожидаемые показания, фактические показания, результат и ссылку на §/рисунок. Отдельно учитывать **SOURCE_GAP**, **NOT_EXECUTED**, **REVISION_DEPENDENT**, **CONFIRMED_MISMATCH**. Свежий moduleidentity baseline `MPSUD_BASELINE.json` удостоверяет DLL/PID предыдущего прогона, но содержит `screen_rendering_accepted=false`; переносить его успех на весь этот перечень нельзя.

## Проверка самого документа

Проверено: последовательность §1.7.2–1.7.17, непрерывность рисунков 1.18–1.39, переходы базовых/ПСН/диагностических окон и явное разделение текстового подтверждения с недоступностью рисунков. Полный РЭ2 PDF отсутствует; production и нативные DLL не изменены.
