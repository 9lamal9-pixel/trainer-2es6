Полный полученный комплект среды разработки 2ЭС6 для Windows.

Исходники привязаны к коммиту этого Release; крупные ресурсы находятся в ZIP-архивах. Для подготовки другого компьютера клонируйте ветку codex/autovedenie и запустите setup.cmd. Для точного воспроизведения снимка можно переключиться на тег trainer-environment-2026-10-16. Подробности: dev/docs/PORTABLE_SETUP.md.

Включены все шесть штатных папок полученного комплекта, отдельная активная копия runtime, разметка и данные мира, документы, DOS-материалы, средства анализа и локальные исторические результаты/сборки. Исторические EXE/результаты сохранены как материалы исследования: setup собирает текущие исходники заново, не принимает старые результаты за новую проверку. Исключены .git, локальное динамическое состояние, вложенные резервные архивы, кэши и посторонний 3dfab_domain_audit.

portable-release.json фиксирует SHA-256, размеры и состав архивов; environment-files.json содержит пофайловую опись. setup проверяет целостность и не перезаписывает отличающиеся рабочие файлы. Доступ к этому Release требует доступа к приватному репозиторию.

Требования: Windows x64, Windows PowerShell 5.1, Git for Windows и .NET Framework 4.x с 32-разрядным компилятором. Переносимый CPython 3.13.16 с pefile/capstone/pip включён в комплект; отдельная установка Python не требуется.

Это предварительный выпуск среды, не готовая сертифицированная модель. АВП отключено, повторное торможение и новая калибровка остаются в работе. Сетевой мост и рендер полного 3D-мира не приняты; зарегистрированные Kornilcevo/main.exe и WorldSkils/main.exe отсутствовали в исходно полученных файлах.

Объём: 17 логических ZIP (332 небольшие части/файла передачи), 2 708 526 175 байт для скачивания; 53 990 файлов (6 613 041 093 байта) и 250 пустых каталогов после восстановления. Рекомендуется 20 ГиБ свободного места для архива, staging и готовой копии.

Крупные ZIP передаются частями по 8 МиБ; setup автоматически собирает исходные архивы, проверяет SHA каждой части и всего ZIP. Загрузка возобновляется после сбоя.
