# История и восстановление

`Checkpoint` сохраняет commit, точный patch commit, Git blob IDs файлов и описание исправления. `Fix` создаёт checkpoint после успешных выбранных проверок. Сборки сохраняют собственную копию исходников, их SHA256, компилятор, аргументы и SHA нативных DLL.

Каждая команда сохраняет `command.json` и `console.log`. Каждый процесс тренажёра имеет отдельный `session.json`, `integration.log`, `telemetry.csv` и копию `build.json`. JSON результатов проб также находится в индивидуальном каталоге; устаревший общий результат не принимается. После завершения native проб сверяются PID, build ID, SHA EXE и отсутствие ошибок сессии. Незавершённые сессии остаются видимыми со статусом running.

```powershell
.\dev\TrainerDev.ps1 -Action Archive -IncludeRuntime
```

Архив содержит `history.bundle` (Git), `artifacts.zip` (код, версии, результаты, накопленные файлы и весь `work`) и `archive.json` (проверочные суммы сохранённых байтов). Без `-IncludeRuntime` большой каталог `work` целиком не включается. Архивирование читает активные файлы с разрешением совместной записи и ограничивает снимок первоначальной длиной. Для завершённой записи последней сессии перед архивированием закройте её; активный последний фрагмент журнала может попасть в снимок частично. Автоматического удаления архивов и логов нет.

Для восстановления выберите **новую пустую папку**:

```powershell
git clone 'ПУТЬ-К-АРХИВУ\history.bundle' 'НОВАЯ-ПАПКА'
Expand-Archive -LiteralPath 'ПУТЬ-К-АРХИВУ\artifacts.zip' -DestinationPath 'НОВАЯ-ПАПКА' -Force
```

Затем выполните `Doctor` в восстановленной папке. Внешние .NET/Python/редактор остаются системными зависимостями; их пути и версии зафиксированы в конфигурации/отчётах, сами установки в архив не копируются. Профиль реестра штатного тренажёра также должен быть настроен на компьютере запуска; `Run` сохраняет прежние значения трёх меняемых параметров в своей сессии.

Для продолжения бот читает `dev/environment-context.json` и `dev/state/context.json`, затем только выбранные файлы. Контекст содержит ссылки на последнюю сборку, проверки, полный регрессионный набор и checkpoint; большие журналы остаются на диске и читаются лишь по конкретной ошибке.
