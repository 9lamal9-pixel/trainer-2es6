# Интеграция Pneumatics / Journal / BrakeTest для 0.7.4

Источник новых модулей: пользовательский `Trainer2TE116_Realistic_Patch_0.7.2 (1).zip` от 14.11.2026. README архива описывает намерения автора, но не является доказательством нормативной или заводской калибровки.

## Выполненные исправления совместимости

- `Pneumatics.Build` принимает реальный тип `Train`, элементы состава — `Wagon`; вымышленные `TrainConfig` и `WagonSpec` устранены.
- `Journal.Route` и `SetRoute` используют реальный `Route` вместо `RouteData`.
- Восстановлены необязательные параметры и исходные имена параметров `Journal.Configure`: существующий вызов `Configure(tripDir)` работает.
- Третий аргумент `Journal.SetRoute` сохранён как число вагонных осей, которое реально передаёт `Simulation`. Ошибочное умножение его на четыре убрано; иначе для 272 осей вычислялась нагрузка на 1088 осей и ошибочно выбиралась формула сопротивления порожних вагонов.
- `JournalInput` восстановлен как класс с исходными значениями по умолчанию (`X=NaN`, `Charge=.49`, `AllowedKmh=-1`, `AmbientC=20`, `Crane=2`, `Reverser=1`). Это сохраняет контракт для частично заполненных входов и существующих проб.
- Для `JournalEntry` восстановлены ненулевые пустые строки по умолчанию.
- Новый `BrakeTest` вынесен из `Journal.cs` в штатный `BrakeTest.cs`. В сборке остаётся одно определение класса.
- Свойства с `=>` заменены на C#5-совместимые getter-ы.
- Вызовы отсутствующего `TrafficLights` перенесены на реальные `Route.IsProhibiting`/`Route.AspectName`; `JournalEntry.ToString` выводит время, код, нарушение и баллы для списка UI.
- Представление `Wk` больше не подделывает температуру для отображения давления РК. Масса `Wk` остаётся суммой РК+ЗК, а давление читается напрямую из РК через внутреннюю ссылку `PressureViewSource`. До исправления физическое ограничение температуры ±15% искажало показание РК при глубоком торможении: при РК=.529МПа и ЗК=0 отображалось приблизительно .363МПа. Это исправление отображения и совместимости, алгоритм перетекания камер не изменён.

## Подтверждённая нормативная регрессия архива

В B9 восстановлены диапазоны превышения зарядного давления для поездов свыше100 осей: после служебного торможения +.02–.06МПа, после экстренного +.10–.12МПа. Основание: локальный документ `brake_analysis/J_tormoza_2026_июля.pdf`, извлечение `rules83_text.json`, с.108, п.10.3.1м/н. В архиве без основания были введены граница350осей, верхняя граница.04 для обычной ступени и нижняя.05 после экстренного. Существующие допуски измерения/срабатывания B9 сохранены; другие нормативные правила целиком не сертифицировались.

## Обязательные проверки новой пневматики

1. Полная сборка .NET Framework с реальными MainForm, Simulation, TripLog, схемой, тестами; проверка отсутствия дубликата BrakeTest.
2. Глубокое и экстренное торможение: `Wk.M == Rk.M + Zk.M`, `Wk.MPa == Rk.MPa`; контроль баланса воздуха, конечных/неотрицательных давлений и масс.
3. Мягкость: медленно снижать ТМ с .53МПа, в том числе на .08 и .10МПа за60с; сверить фактическое отсутствие ложного срабатывания с подтверждённой характеристикой прибора. Есть риск: РК→ЗК с tau14/60 вместе с ЗК→ТМtau8 создаёт задержку и условие RK−TM>.013 может сработать уже на таком медленном снижении. README не заменяет этот тест.
4. Отпуск I→II, ликвидация завышения УР, отсутствие повторного ложного торможения, полная зарядка после отпуска, затем повторная служебная ступень. В I новый код после прямой подачи вызывает Relay, который при TM>UR открывает выпуск; нужно измерить фактические расходы и время зарядки.
5. Служебный V→IV, повторная ступень и дополнительная разрядка: время распространения волны, ТЦ всех вагонов, равнинный/горный режимы, плотный/разреженный состав, отключённые ВР.
6. Холодная зарядка, разрыв ТМ и закрытый концевой кран: никакого создания воздуха вне компрессора; корректная изоляция и распространение разрядки.
7. Компрессоры: отдельные секции и их выключение, регулятор7.5/9.0, штатная подача электропривода и ограничение питания. Не выводить механическую зависимость подачи от оборотов дизеля без проверки реальной электрической схемы.
8. Journal: частично заполненный JournalInput, B9 служебный+.03/+.055 и экстренный+.06/+.11, границы100/300/350осей; B10/B11 выдержки и хвостовой отпуск; сохранение весовой нормы по реальному числуосей.
