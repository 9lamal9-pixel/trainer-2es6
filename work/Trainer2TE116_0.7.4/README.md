# Сборка 0.7.4 (15.11.2026)

Обновление модулей тяги, пневматики и журнала из предоставленного архива с исправлениями совместимости. Актуальные изменения и ограничения: RELEASE_NOTES_0.7.4.md. Историческое описание ниже сохраняет происхождение проекта; текущие результаты проверок приведены в VALIDATION_0.7.4.md.

# Новый инструктор 2ТЭ116 (Trainer2TE116)

Программа инструктора тренажёра 2ТЭ116 «Фантомас», написанная с нуля по ТЗ [TZ_TRAINER_2TE116.md](../../docs/fantomas/TZ_TRAINER_2TE116.md). Версия 0.7 от 11.11.2026 — готовый билд для установки с флешки: пульт, видеосистема, БЛОК, модель дизелей и электропередачи.
- **Ставится рядом с установленной.** Работает вместо `instructor.exe`; файлы, настройки и база тренажёра не меняются.
- **Берёт данные тренажёра только на чтение:** сценарии `RTS/scenaries/*.json`, составы из `RTS/database/Program_data.db`, картинки знаков и светофоров из ресурсов `instructor.exe`.
- **Пишет только в свою папку** `data/`.

## Пневматика: обновление 13.11.2026

- Главные резервуары — 4 × 250 л на секцию (`Pneumatics.Mr`, 2000 л на тепловоз), по схеме воздухопровода 2ТЭ116.
- Питательный резервуар 250 л на секцию за обратным клапаном 17 (`Pneumatics.Pr`): заряжается вместе с ГР, обратно воздух не отдаёт. Через реле давления № 304 из него наполняются ТЦ тепловоза (кран № 254 и воздухораспределитель) — не выше его давления и с расходом его воздуха. Давление показано в разделе «Локомотив» и на схеме пневматики.
- Плотность ТЦ тепловоза (`Pneumatics.LocoTcLeak`; Правила ТО тормозов 2025, п. 4.1, смена кабин): кран № 254 в последнем тормозном положении, ТМ разряжена краном № 395 до нуля, разобщительный кран к ТЦ перекрыт (`LocoTcCut`) — ТЦ теряют около 0,1 кгс/см² за минуту при норме не более 0,02 МПа (0,2 кгс/см²); при открытом питании реле № 304 восполняет утечку из питательного резервуара.
- Журнал нарушений: запись `D1`, если продольная сила в автосцепке больше `Journal.CouplerLimitKn` = 1275 кН (130 тс по ПТР), не чаще раза в минуту.
- Проверки стенда (`test/Bench.cs`): объёмы, обратный клапан, наполнение ТЦ из питательного резервуара.

Подача компрессора от оборотов дизеля не зависит, продольная динамика с автосцепками и таблица давлений по вагонам (раздел «Поезд») в программе уже были.

## Оригинальная кликабельная схема (версия 0.7)

Восьмая вкладка «Схема» показывает исходные семь страниц пользовательского PDF без перерисовки. Поддерживаются поиск, масштаб, сдвиг, состояния и дефекты поверх рисунка. Для повторяющихся обозначений выбирается конкретная цепь; неподтверждённый контакт не назначается автоматически. Лист работает как карта: провода под напряжением светятся оранжевым прямо на рисунке, по проводу и по обозначению можно щёлкнуть (состояние, обрыв, перемычка); сверху — строка «что сейчас собрано». Светятся только провода, номера которых есть в модели. Первая страница пневматики пока справочная. Доступен также диагностический режим «Цепи модели».

Граф схемы управляет аппаратами пуска, тяги, компрессора, холодильника, защит, ламп и освещения. Описание работы, подтверждённые уточнения к плану и ограничения: [SCHEME_IMPLEMENTATION.md](../../docs/fantomas/SCHEME_IMPLEMENTATION.md). Итоговые отчёты — в `out/bench_report.txt`.

## Готовый билд и установка с флешки (версия 0.7)

`.\package.ps1` прогоняет все проверки и собирает `out\dist\Trainer2TE116_0.7\` и `Trainer2TE116_0.7.zip` (с оригинальными листами схемы). Папку или архив переносят на флешку.

| В пакете | Что делает |
|---|---|
| `Установить.cmd` | Ставит в `C:\Trainer2TE116` (папку можно сменить) и ищет папку тренажёра: запущенный `instructor.exe`, прежние настройки, обход дисков. Показывает адрес пульта из `logic_config.json`. По согласию добавляет правило брандмауэра для UDP 2001 только этой программы (Windows спросит права). Создаёт ярлыки «Инструктор 2ТЭ116 (новый)» на рабочем столе и в «Пуске». При обновлении поездки, свои поезда и настройки сохраняются |
| `Запустить с флешки.cmd` | Работа без установки, данные пишутся на флешку |
| `ПРОЧТИ.txt` | Инструкция для инструктора |
| `program\Проверка пульта.cmd` | Нативный тест на месте: программа и эмулятор пульта на этом компьютере (настоящий пульт не задействуется), 46 проверок, «PULT PASS» |
| `program\Удалить.cmd` | Убирает ярлыки, правило брандмауэра и программу; данные можно оставить. В папке с `instructor.exe` не работает |

Программа в этом билде работает сама, без машины разработки.
- **Папка тренажёра** ищется так: ключ `--release`, `settings.json`, папки вокруг программы, запущенный `instructor.exe`. Если не найдена — программа один раз спрашивает её и запоминает. Из папки тренажёра только читается.
- **Защиты.** Вторая копия не запускается. Пока открыт `instructor.exe`, программа предлагает закрыть его, работать без пульта или выйти. Непредвиденные ошибки пишутся в `data\errors.log`.
- **Требования:** Windows 64 бит, .NET Framework 4.5+ (на Windows 10/11 есть). SQLite едет в пакете.

Проверено на этой машине: архив распакован как флешка, установка в чистую папку (тренажёр найден обходом дисков за 13 с), обновление поверх с сохранением своих поездов. Установленная программа открывает окно; вторая копия получает сообщение «уже запущена». Самопроверка установленной программы — PULT PASS (в версии 0.4 — 35 проверок; пакет 0.5 проверен так же, см. ниже). Удаление работает с сохранением данных и без; папку тренажёра удаление трогать отказывается. На машине тренажёра и с настоящим пультом билд ещё не запускался, ярлыки и правило брандмауэра в проверке не создавались.

## Пульт кабины (версия 0.3)

Обмен такой же, как у `instructor.exe` (декомпилированные `PultAsyncClient`, `PultManager`, `Te116Logic`, разбор — [IO_2TE116.md](../../docs/fantomas/IO_2TE116.md)).
- **Транспорт.** Один UDP-сокет на своём порту 2001: принимает пакеты пульта, раз в 25 мс шлёт пульту стрелки и лампы на `ip_pult:port_pult` из `Data\logic_config.json` тренажёра (читается, не меняется).
- **Вход — 48 байт, байт = ячейка.** В органы кабины идут: 2 ключ ЭПК, 3 педаль и 4 кнопка песка, 15 песок под первую ось, 5 тифон, 6 свисток, 7 реверсор (2 вперёд, 1 нейтраль, 0 назад), 8 контроллер 0–15, 13/14 прожектор, 16 кнопка отпуска (254 в 1), 18 бдительность, 22 и 23 «управление тепловозом» и «движение» (оба включены — тяга разрешена), 44 кран 395 (1–7, 6 — VI, 7 — Vа), 45 кран 254 аналогом (152 → 1, 145 → 2, 132 → 3, 119 → 4, 101 → 5, ниже — 6).
- **Ячейка применяется, когда меняется** (и все — с первым пакетом поездки). Поэтому инструктор может сдвинуть рукоятку на экране, пока пульт стоит.
- **Выход — 43 байта.** 15 стрелок по 2 байта, старший первым, код 0–999: масло 1 и 2–3 секций (кгс/см² / 15), температуры масла и воды (°C / 120), ТЦ 1 и 2, УР (кгс/см² / 10), ТМ и ГР (кгс/см² / 16), ток батареи ((150 + А) / 300), напряжение (кВ) и ток (А / 6000) генератора, указатель неисправности. Затем 13 ламп: сброс нагрузки 1 и 2, уровень воды, давление масла, (пусто), ТМ, «заторможен» (ТЦ выше 0,04 МПа), пожар, работа дизеля 2, охлаждение, РЗ, бдительность, ПСС.
- **Стрелки ГР и ТМ переставлены** (`--pult-swap 1` по умолчанию): пульт подключён ГР ↔ ТМ, та же поправка, что в пакете модели.
- **Откуда значения.** Масло, вода, ток батареи, ток и напряжение генератора, указатель неисправности и лампы идут из модели дизелей (`Traction.cs`), лампа ТМ — от датчика 418 и РУ1, лампы «Бдительность» и ПСС — от БЛОК. Лампы пожара, охлаждения и РЗ не загораются.
- **Тумблеры и кнопки дизелей:** аварийная кнопка (36), топливные насосы (37/39), ПУСК 1/2 (38/40), «Управление тепловозом» (22), «Движение» (23), ослабление поля (24), холодильник (25), вентиляторы 1–4 (26–29), сигнализация (34), указатель неисправностей (31–33). Что они делают — в разделе «Дизели, электропередача, датчик 418».
- **Ячейки дизелей применяются только при изменении:** поездка начинается с работающими дизелями, как бы ни стояли тумблеры.
- **Ускорение времени** при пульте на связи не действует (ТЗ, раздел 7). Исключение — стенд, запущенный с ключом `--speed`.
- **Связь** показывается в шапке, на вкладке «Поездка» и в карточке кабины. Появление и потеря связи пишутся событием поездки и в кассету.

Нативный тест `test\PultTest.cs` проверяет программу так, как с ней работает настоящий пульт.
- **Запуск.** Эмулятор занимает свободный UDP-порт 127.0.0.1 как пульт и запускает `Trainer2TE116.exe` отдельным процессом с этим пультом, поездкой из командной строки, прозрачным окном и ускорением ×5.
- **Управление — только ячейками пульта:** ЭПК, 254 (6 → 2), свисток, реверсор, контроллер до 6, кран 395 (II, V, IV, I, II), ключ ЭПК выключен на ходу, VI, восстановление ЭПК и зарядка, аварийная остановка и ПУСК дизелей, выключение топливного насоса. В пути приходит повреждённый пакет — он должен игнорироваться.
- **Реакция читается** из 43 байт, которые программа шлёт пульту, и из кассеты поездки.
- **Закрытие** — как у инструктора (WM_CLOSE). Затем проверяются кассета, события и журнал.

## Дизели, электропередача, датчик 418 (версия 0.5)

Модель локомотива перенесена из пакета для прежнего инструктора (`brake_proxy/LocoModel.cs`) с его уставками.
- **Пуск и остановка.** Топливный насос, контроллер на 0, реверсор в рабочем положении, ПУСК: прокачка масла 60 с (РВП1), прокрутка 12 с (РВП2) — пуск около 72 с. Остановка насосом, затем 60 с прокачки — повторный пуск только после неё. Поездка начинается с работающими прогретыми дизелями.
- **Тяга.** Схема собирается только с 1-й позиции (РУ8). Реверсор блокируется, пока контроллер не на нуле. Регулятор держит обороты позиции, индуктивный датчик снимает нагрузку при перегрузке дизеля. Возбуждение ГГ: ограничения по току позиции, 700 В и мощности; на холостом ходу 80 В для вентиляторов. Ослабление поля 42/62 км/ч, только с 4-й позиции.
- **Вспомогательные машины.** Вентиляторы ТЭД, выпрямителя и четыре вентилятора холодильника берут мощность у тяги; холодильник включается по температурам воды и масла.
- **Защиты.** РДВ (ТМ ниже 0,294 МПа), ДПТ (кран 254: ТЦ выше 0,22 МПа — на 3-й и 4-й ступенях можно брать тягу для плавного трогания, с 5-й тяга снимается), РУ1 (разрядка ТМ не краном), ЭПК, РП3 на 110 км/ч (РУ2 держится до постановки контроллера на ноль), ТРВ 96 °C, ТРМ 88 °C, давление масла (сброс нагрузки ниже 0,10, остановка ниже 0,07 МПа). После защиты — с 1-й позиции.
- **Аварийная кнопка** глушит оба дизеля, разряжает ТМ и даёт песок; действует при включённых АУ, блокировке № 367 и реверсивной рукоятке в рабочем положении; сбрасывается постановкой реверсивной рукоятки в нейтраль или автоматом АУ.
- **Состояние дизелей:** `diesel_condition` в `settings.json` — `nominal`, `normal` (по умолчанию), `worn`, `random` или процент. Секции отличаются на 5–10 %; у изношенной машины меньше мощность, выше температуры, возможны срабатывания РДМ.
- **Неисправности инструктора:** 16 электрических (топливо, нагрузка, реверсор, РМ1, КТН, боксование, охлаждение, масло и др.) и 14 тормозных.
- **Срыв ЭПК и обрыв ТМ:** кран машиниста питает ТМ из ГР установленным порядком, без блокировки.
- **Датчик 418 (лампа «ТМ»)** по Правилам ТО тормозов 2025: загорается на ступени 0,02–0,03 МПа при срабатывании ВР и гаснет после дальнейшего снижения УР на 0,04 МПа (п. 3.2.21); не горит при ликвидации сверхзарядки (п. 3.2.8), на заряженном поезде и при зарядке после отпуска; горит при обрыве и открытом концевом кране (пп. 9.8.2, 10.1.20). На длинном поезде (100 вагонов) ступень 0,025 МПа лампу не зажигает: подпитка крана почти не растёт.

## Цепи по схеме 2ТЭ116, вариант 008 (версия 0.6, 11.11.2026)

Модель сверена с альбомом схем (8 вариант), методичкой «Аварийные схемы 2ТЭ116 (вариант 008)» и серией статей В. П. Анисимова «Электрическая схема тепловоза 2ТЭ116» («Локомотив», 2016–2017). Описание работы каждой схемы и сверка с органами пульта — [SCHEMES_2TE116.md](../../docs/fantomas/SCHEMES_2TE116.md).
- **Аппараты вне пульта** (`src/Circuits.cs`, карточка «ВВК и автоматы» в разделе «Локомотив»): рубильник АБ, автоматы АУ, А1–А6, А12, АВУ, 1АТ, 2АТ, АМК, блокировка № 367, ТРК, ВРЗ, аварийное возбуждение АП, аварийный топливный насос ТНА, двери ВВК, отключатели моторов ОМ1–ОМ6. Инструктор работает ими за помощника машиниста.
- **Защиты силовой цепи:** РЗ, РОП, РМ2 с защёлкой, сброс повторным включением А4; секция работает на оставшихся моторах при выключенном ОМ.
- **Компрессор** работает от своего электродвигателя и не зависит от оборотов дизеля; пуск через резистор 2 с.
- **Холодильник:** «Автомат» — только термореле (вода 75 / 79 / 83 °C, масло 62 / 67 / 72 °C), «Ручное» — только тумблеры Т1–Т4 (Т2 после Т1, Т3 после Т4); в нейтрали реверсивной рукоятки не управляется.
- **Обороты по позициям** — по таблице журнала: 350, 395, 445 … 955, 1000 об/мин. ТОБ действует с 3-й позиции.
- **Лампы пульта** «Пожар», «Охлаждение», «РЗ», «Уровень воды» теперь загораются; тумблер «Повреждение» оставляет лампы второй секции. «Заторможен», «Давление масла», «Уровень воды», «РЗ» горят только при реверсивной рукоятке в рабочем положении. «Сброс нагрузки» горит и на холостом ходу, если возбуждение секции снято.
- **Все лампы по листу 8 схемы:** у каждой своё питание (А4, АУ через реверсивную рукоятку, АУ или А3 секции); «Контроль ламп» зажигает «Уровень воды», «Давление масла», «Отпуск тормозов». В карточке «Кабина» лампы показаны как на пульте; щелчок по лампе «пережигает» её — машинист должен найти это проверкой ламп.
- **Указатель повреждений** показывает три цепи схемы: «Пуск», «Возбуждение», «Движение».
- **Пульт:** читается ячейка 35 «Боксование» (ТОБ).
- **Карточка «Кабина»** получила тумблеры и кнопки пульта, которых не было на экране: тяга, холодильник, топливные насосы, пуск, аварийная остановка, указатель повреждений.
- **15 новых неисправностей** по схемам (коды 117–131).

На пульте и на живом тренажёре это не запускалось.

## Видеосистема и БЛОК (версия 0.5)

Обмен такой же, как у `instructor.exe` (декомпилированные `ClientVideo`, `VideoDataReceiveController`, `BLOKManager`, `BLOKDataReceiveController`); код — `src/Links.cs`.
- **Адреса** — из `Data\logic_config.json` тренажёра (`ip_video`, `port_video`, `ip_blok`, `port_blok`).
- **Номер видеомаршрута** выбирается под сценарий при каждом «Начать поездку»: по первой и последней станции сценария ищется разметка `RTS\scenaries\root\N.json`, иначе берётся участок сценария из базы инструктора, иначе остаётся номер из `RTS\start_markup_data.json`. При смене маршрута видеосистеме посылается стоп и новый пуск. Ключ `--road` или `road` в `settings.json` отключает подбор. С настоящей видеосистемой смена маршрута не проверялась.
- **Место старта** — `start_coord` сценария (голова не ближе длины поезда + 60 м от начала), а не выходной светофор первой станции.
- **Положение органов пульта.** С первым пакетом пульта в модель переносятся все его тумблеры, включая «Топливный насос»: если он выключен, дизель этой секции в начале поездки стоит. Без пульта дизели, как раньше, запущены. Аппараты не с пульта (ВВК, дизельное помещение) остаются подготовленными.
- **Секции на экране.** Флажки кабины и аппаратных камер раз в 0,5 с сверяются с моделью и показывают выбранную секцию. Аппараты, которые в схеме одни на тепловоз (БУ, ТРК, А14, освещение), показаны серым и действуют одинаково при любой выбранной секции.
- Свои значения: `video`, `blok` (auto | off | ip:port) и `road` в `settings.json` или ключи `--video`, `--blok`, `--road`.
- **Видео (TCP).** После подключения — пуск маршрута (паузы 3 с до и после, как у оригинала), затем все светофоры, знаки и включённые препятствия сценария. Дальше раз в 0,1 с — изменения: место, скорость и допустимая скорость, показания светофоров, новые знаки и предупреждения, препятствия, день и ночь, дождь, снег, туман, прожектор, звуки. На паузе звуки выключаются. При закрытии окна — стоп.
- **БЛОК (UDP, раз в 25 мс, 146 байт).** Давления ТМ, ТЦ, УР, ГР, скорость, ускорение, уклон, координата по пикетам, станция, название и код следующего светофора, расстояние до него, ограничение по ЭК, ключ ЭПК, РБ и РБС, клавиши КЛУБ с пульта, тяга, направление, срыв ЭПК. Признаки: ЭК есть, САУТ нет.
- **Ответ БЛОК (10 байт).** Удерживающая катушка ЭПК: нет катушки при включённом ключе — свисток 7 с, затем срыв. Лампы «Внимание» и ПСС идут на пульт. Допустимая скорость БЛОК передаётся видеосистеме.
- **Без связи** программа работает как раньше: катушка считается включённой, допустимая скорость своя. Состояние трёх связей — в шапке («Пульт · Видео · БЛОК») и на вкладке «Поездка»; появление и потеря пишутся в события и кассету.
- **Препятствия, поставленные с карты** в произвольном месте, на видео не появляются: у видеосистемы есть только объекты сценария.

| Насосы включены, аварийная остановка; ПУСК 1 и 2; насос 2 выключен | Давление масла 0 и лампа «дизель 2» гаснет; масло 3,4 кгс/см² у обеих секций; дизель 2 снова остановлен |
| Окно закрыто (WM_CLOSE) | Выход 0; CRC кассеты без ошибок; в кадрах краны I, II, IV, V, VI, контроллер до 6, реверсор, 254 в 6 и 2, свисток, срыв ЭПК; события «Пульт кабины: на связи», «ЭПК: ключ выключен на ходу…», «Окно инструктора закрыто»; в журнале O4 |

- **Видеосистема (эмулятор TCP).** Получает пуск маршрута с его номером, 128 светофоров и 110 знаков сценария, место и скорость поезда, звуки дизеля, свистка, крана V и VI, свисток ЭПК, а при закрытии окна — стоп.
- **БЛОК (эмулятор UDP).** Получает пакеты по 146 байт с давлениями, названием светофора и станции, ограничением 80. Лампа «Внимание» из ответа БЛОК загорается на пульте. Снятая удерживающая катушка даёт свисток и срыв ЭПК, после её возврата и VI положения ЭПК восстанавливается.
- **Найдено тестом.** Если после срыва ЭПК оставить кран 395 во II, реле продолжает питать ТМ: она держится около 0,17 МПа, ГР за минуту садится до 0,35 МПа. Тест поэтому ставит VI сразу, как велит инструкция.
- **Не проверено.** Равна ли площадь срывного клапана ЭПК в модели (2·10⁻⁴ м²) настоящей, по паспорту ЭПК-150 не сверено.

## Запуск

```
.\build.ps1                         # out\Trainer2TE116.exe (+ SQLite из установки тренажёра)
.\package.ps1                       # проверки + пакет для флешки out\dist\Trainer2TE116_<версия>(.zip)
out\Trainer2TE116.exe               # окно инструктора, пульт по Data\logic_config.json тренажёра
out\Trainer2TE116.exe --pult 192.168.0.176:2000 --pult-local 2001 --pult-swap 1   # пульт явно; --pult off — без пульта
out\Trainer2TE116.exe --start --scenario <json> --train builtin:0 --speed 5 --data <папка>   # поездка сразу (стенды)
out\Trainer2TE116.exe --run --scenario <...\RTS\scenaries\1_1.json> --train builtin:3 --out <папка>   # прогон без окна
```

Папка тренажёра и пульт — в `settings.json` рядом с программой (`release_dir`, `pult`: auto | off | ip:port, `pult_local`, `pult_swap`); ключи командной строки важнее. Без настройки программа ищет папку сама (раздел «Готовый билд»).

Порт 2001 занимает и `instructor.exe`. Если он запущен, новая программа пишет «порт 2001 занят» и работает без пульта. Одновременно с пультом может работать только одна из программ.
