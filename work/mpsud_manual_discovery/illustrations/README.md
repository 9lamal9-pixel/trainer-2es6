# Изображения экранов из вторичной перепечатки

Источник: description_mpsud_2017.pdf, 46 страниц; Writer/LibreOffice 6.0, дата создания 14.03.2019. Форумное размещение 2017 года не доказывает дату создания этой версии. Это **SECONDARY_REPRINT**, не установленный заводской оригинал РЭ.

22 исходных PNG: SR00.png…SR21.png. 20 изображений имеют размер 801×599 и прозрачность PDF softmask; два (SR10/SR12) — непрозрачные RGB 640×480. Исходные размеры и пиксели сохранены без ресэмплинга. PNG-контейнер создан pypdf из встроенного изображения; исходный поток PDF имеет другой формат.

22 файла white/SRxx.png — отдельные варианты на белой подложке для просмотра; размеры не изменены. SHA исходного PNG и white_preview_sha256 хранятся отдельно в illustrations.json. Чёрная подложка исходных RGBA скрывает часть тёмного текста, поэтому для чтения следует использовать белые варианты либо белый фон контейнера.

Сопоставление со страницами основано на ContentStream Do и подписях. page.images содержит 22 общих ресурса на каждой странице и сам по себе не даёт корректного соответствия страницы и изображения.

Все 22 исходных и 22 белых варианта просмотрены в полном размере. Основные подписи читаются; мелкий текст и сокращения ограничены, SR04 имеет низкий контраст. Цветовая и пиксельная идентичность заводским рисункам не подтверждена.

SR20 содержит списки «Связь»/«Неиспр. БУК» и пустую таблицу кодов «Линия 1/2»; смысл кодов 0–5 требуется брать из текста. SR21 показывает версию 2.03 (25.10.2007) и минуты 36.
